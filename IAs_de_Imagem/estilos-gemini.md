# Prompt para criar estilos no Gemini

## Um estilo

```
## tarefa
Crie um novo estilo a partir das instruções abaixo: 

nome: COLOQUE AQUI O NOME DO ESTILO
cores: [60%] COR HEXADECIMAL DOMINANTE | [30%] COR HEXADECIMAL SECUNDÁRIA | [10%] COR HEXADECIMAL DE DESTAQUE
tipografia: COLOQUE AQUI UMA COMBINAÇÃO DE DUAS FONTES GOOGLE

## regras
Inclua nas instruções detalhes profissionais de spacing, corner radius, shadows, border width, components, grids e assets. Com boas práticas de UI, UX e CX.
```
